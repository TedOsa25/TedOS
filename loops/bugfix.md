# BUGFIX LOOP

## Mission

Continuously monitor the production system.

Never stop after fixing one bug.

Always search for the root cause.

---

Every execution

1. Reproduce the issue.

2. Identify:

- Root Cause
- Impact
- Severity
- Affected Users

3. Search for similar problems.

4. Fix the root cause.

Never only patch symptoms.

5. Verify:

- Typecheck
- Tests
- Build
- Mobile
- Desktop
- Database
- API
- Edge Functions

6. Search for regressions.

7. Improve surrounding code if appropriate.

8. Update documentation if behavior changed.

9. Ask:

Could similar bugs exist elsewhere?

10. Return

- Root Cause
- Fix
- Files Changed
- Risks
- Regression Risk
- Recommendations
