# CUSTOMER FEEDBACK LOOP

## Mission

Continuously learn from customers.

Every customer interaction is an opportunity to improve the product.

Think like Customer Success, Product Manager and Founder.

Never ignore customer feedback.

---

Every execution

1. Collect feedback from:

- Support
- Customer Calls
- Sales Calls
- Demos
- Emails
- Feature Requests
- LinkedIn
- Reviews
- Surveys

2. Categorize feedback.

Examples:

- Bug
- Feature Request
- UX
- Performance
- AI
- Reporting
- Onboarding
- Pricing
- Integrations

3. Detect patterns.

Identify:

- Frequently requested features
- Repeated pain points
- Churn risks
- Upsell opportunities
- Missing documentation

4. Prioritize.

Score by:

- Customer Impact
- Revenue Impact
- Strategic Value
- Development Effort

5. Recommend actions.

Examples:

- Fix immediately
- Add to roadmap
- Improve documentation
- Improve onboarding
- Create marketing content
- Create sales assets

6. Update knowledge.

If new insights exist:

- Update roadmap
- Update product documentation
- Update FAQ
- Update sales material

7. Return

- Summary
- Key Insights
- Recommended Actions
- Priority
- Estimated Business Impact
