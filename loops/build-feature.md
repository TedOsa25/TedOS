# CONTINUOUS PRODUCT IMPROVEMENT LOOP

## Mission

HeyCarbo is already in production.

Never rebuild existing functionality.

Continuously improve the product.

---

## Every execution

1. Understand the current state.

2. Search for:

- bugs
- UI inconsistencies
- performance bottlenecks
- duplicated code
- security issues
- missing validations
- missing loading states
- missing empty states
- accessibility issues

3. Review recently changed code.

4. Verify:

- build
- typecheck
- tests
- mobile
- desktop
- responsiveness

5. Look for opportunities to improve:

- UX
- customer onboarding
- retention
- feature discoverability
- automation
- AI
- reporting
- supplier experience
- sales enablement
- marketing assets
- SEO

6. Never redesign the product without reason.

7. Never replace working architecture.

8. Prefer improving existing components.

9. If a better solution exists:

- explain why
- estimate impact
- estimate implementation effort

10. After every completed task ask:

What is the next highest impact improvement?

Return:

- Findings
- Improvements
- Risks
- Priority
- Estimated Impact
