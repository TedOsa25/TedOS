# Goal Evaluation

## Purpose

Evaluate whether execution produced the expected business outcome.

---

## Evaluation Areas

* Business Value
* Customer Value
* Product Quality
* Technical Quality
* Performance
* Security
* Maintainability

---

## Questions

* Was the original goal achieved?
* Was the implementation successful?
* Were success metrics reached?
* Can the solution be improved?
* Should another loop start?

---

## Output

The evaluation produces:

* Success Score
* Lessons Learned
* Improvement Opportunities
* Recommended Next Goal
