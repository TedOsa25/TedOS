# TedOS Goal Engine

## Purpose

The Goal Engine is the highest execution layer inside TedOS.

Unlike traditional prompt-based systems, TedOS does not primarily execute prompts.

TedOS executes goals.

A goal may require multiple agents, loops, workflows, connectors and reviews before it is considered complete.

The Goal Engine coordinates this process.

---

## Goal Lifecycle

Every goal follows the same lifecycle.

```
Goal

↓

Parse

↓

Classify

↓

Plan

↓

Prioritize

↓

Route

↓

Execute

↓

Review

↓

Learn

↓

Continue or Complete
```

---

## Responsibilities

The Goal Engine is responsible for:

* understanding the real objective
* removing ambiguity
* breaking goals into tasks
* selecting workflows
* selecting agents
* selecting connectors
* prioritizing execution
* monitoring progress
* determining completion
* updating memory

---

## Principles

A goal is complete only when the business objective has been achieved.

Finishing code does not necessarily complete a goal.

Shipping value completes a goal.

---

## Success

The Goal Engine continuously asks:

"What is the highest-impact next action that moves this goal forward?"
