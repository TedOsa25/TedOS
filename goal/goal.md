# Goal

## Definition

A Goal is the highest-level objective inside TedOS.

Every action, workflow, loop and agent exists to move a goal forward.

A goal is business-oriented rather than task-oriented.

---

## Goal Structure

Every goal contains:

* Goal ID
* Title
* Description
* Business Objective
* Priority
* Status
* Owner
* Required Agents
* Required Skills
* Required Connectors
* Success Criteria
* Dependencies
* Current Progress
* Next Action

---

## Goal States

A goal moves through the following states:

Backlog

↓

Ready

↓

Planning

↓

Executing

↓

Review

↓

Completed

↓

Archived

---

## Goal Types

Examples:

* Feature Development
* Product Improvement
* Bug Resolution
* Research
* Marketing Campaign
* Sales Initiative
* Customer Success
* Infrastructure
* Security
* Documentation

---

## Success Criteria

A goal is complete only if:

* Business objective achieved
* Success criteria met
* Review passed
* Memory updated
* Documentation updated
* Runtime updated

Completion of code alone does not complete a goal.
