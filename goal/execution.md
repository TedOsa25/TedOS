# Goal Execution

## Purpose

The Execution Engine carries out the approved execution plan.

---

## Execution Cycle

Plan

↓

Execute

↓

Validate

↓

Review

↓

Improve

↓

Repeat

---

## Rules

Always:

* Execute one milestone at a time.
* Validate after every milestone.
* Stop on critical errors.
* Update Runtime continuously.
* Respect all active policies.

---

## Outputs

Execution produces:

* Progress Updates
* Runtime Updates
* Memory Candidates
* Review Requests
* Completion Status
