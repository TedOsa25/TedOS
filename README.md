# TedOS

TedOS is a modular AI Operating System designed to build, operate and scale multiple AI-native software products from a shared intelligence layer.

## Current Products

* HeyCarbo
* HeyAudit
* HeyMigo

## Architecture

TedOS consists of:

* Core
* Policies
* Templates
* Skills
* Knowledge
* Memory
* Agents
* Subagents
* Loops
* Playbooks
* Subsystems
* Workflows
* Connectors
* Automation
* Runtime

## Goals

* Reuse knowledge across products
* Standardize development workflows
* Reduce repetitive work
* Increase software quality
* Scale with AI
