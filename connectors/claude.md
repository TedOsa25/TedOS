# Claude Connector

## Purpose

The Claude Connector enables TedOS to delegate implementation work to Claude Code.

---

## Responsibilities

* Execute Coding Tasks
* Review Existing Code
* Refactor Code
* Generate Documentation
* Run Development Loops
* Report Progress

---

## Inputs

* Goal
* Context
* Repository
* Files
* Instructions

---

## Outputs

* Code Changes
* Reports
* Documentation
* Pull Requests
* Progress Updates

---

## Security Rules

* Never modify production systems without approval.
* Respect project architecture.
* Keep implementations modular.
* Report failures immediately.

---

## Typical Workflows

* Feature Development
* Bug Fixes
* Refactoring
* Documentation
* Code Review
