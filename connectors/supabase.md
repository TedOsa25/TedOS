# Supabase Connector

## Purpose

The Supabase Connector enables TedOS to interact with the Supabase backend.

---

## Responsibilities

* Read database records
* Write database records
* Execute SQL queries
* Run database migrations
* Manage Row Level Security (RLS)
* Execute Edge Functions
* Manage Storage Buckets
* Handle Authentication
* Monitor database health

---

## Inputs

* Database
* Tables
* SQL Queries
* Migrations
* Edge Functions
* Storage

---

## Outputs

* Query Results
* Migration Status
* Authentication Status
* Storage Status

---

## Security Rules

* Never modify production data without approval.
* Always respect Row Level Security.
* Validate migrations before execution.
* Keep database changes reversible.

---

## Typical Workflows

* Database Migration
* Authentication
* File Uploads
* Edge Functions
* Reporting
* Data Import
