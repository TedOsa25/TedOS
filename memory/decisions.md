# DECISIONS MEMORY

## Purpose

Store long-term engineering, product and business decisions.

Never repeat the same discussions.

Always respect previous decisions unless explicitly changed.

---

## Product

- Production stability has higher priority than new features.
- Improve existing functionality before rebuilding it.
- Never rewrite working code without measurable business value.
- Prefer incremental improvements over large refactorings.

---

## Engineering

- Reuse existing components whenever possible.
- Never duplicate business logic.
- Keep architecture modular.
- Mobile-first by default.
- Accessibility is required.
- Performance is a feature.

---

## Database

- Respect existing schema.
- Respect Row Level Security.
- Prefer migrations over manual database changes.
- Never modify production data without validation.

---

## AI

- AI should automate repetitive work.
- AI should explain its reasoning.
- AI should never invent business data.
- AI should improve products continuously.

---

## Sales

- Research before outreach.
- Personalization over volume.
- Business value before technical features.
- Every outreach should solve a real customer problem.

---

## Marketing

- Every new feature is a marketing opportunity.
- Product updates should generate content.
- SEO should grow continuously.
- Documentation is part of marketing.

---

## Product Philosophy

Always optimize for

- Customer Value
- Revenue
- Retention
- Simplicity
- Automation
- Scalability
- Maintainability

Never optimize only for engineering elegance.

---

## Continuous Improvement

After every completed task ask

- Can the product improve?
- Can sales improve?
- Can marketing improve?
- Can onboarding improve?
- Can automation improve?
- Can customer success improve?
- Can documentation improve?

If yes, suggest the next highest-impact improvement.
